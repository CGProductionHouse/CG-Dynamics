## Project use

1. Preview candidates in Envato and choose only the cues the edit needs. Record the item URL, author, role, chosen file, source in/out, timeline time and gain in the project manifest.
2. Download/register a separate Envato license for the exact client end product. Save its license proof in that project's private source folder. Reuse in another project requires a new license registration while the subscription is active.
3. Import the project-licensed file into Premiere's project bin or the project's linked media folder. Keep it on its own timeline track. Do not publish a common raw WAV/MP3 pack or place unmodified stock assets in a generally shared Adobe Library.
4. The signed-in account displayed **Core Individual Subscription** on 20 October 2026, with a “Switch to a Teams plan” option. Staff cannot rely on this individual's Workspace or login as a shared subscription. The repo catalog gives staff the candidate links now; an Envato Teams plan with named seats would be needed for shared team access and individual project licensing. Do not share the individual login or change the paid plan without the owner choosing that cost.
5. If CG later uses an Adobe Creative Cloud Library for cleared company-owned recordings or other assets whose licenses permit central reuse, confirm storage quota, sharing roles and Premiere import on a staff device before declaring that workflow ready.

The subscription's [one-project-per-license terms](https://help.elements.envato.com/hc/en-us/articles/360000628966-Envato-Elements-License) and [fair-use policy](https://help.elements.envato.com/hc/en-us/articles/360000621743-Fair-Use-Policy) prohibit using the subscription to bulk stockpile a generic downloaded asset library. Adobe documents [shared Creative Cloud Libraries](https://helpx.adobe.com/creative-cloud/apps/create-and-manage-libraries/create-and-organize-libraries/libraries-overview.html) and [access from Premiere](https://helpx.adobe.com/premiere/desktop/collaborate-with-others/collaborate-using-creative-cloud-libraries/about-creative-cloud-libraries.html), subject to storage and the rights of each asset.
