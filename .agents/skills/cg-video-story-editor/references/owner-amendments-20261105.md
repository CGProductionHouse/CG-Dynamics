Never reuse the same original footage recording in separate shots of one film.
Nonoverlapping ranges, new crops, speed changes, grading, renamed files and
re-encodes do not make a different clip. Bind the original recording identity
when using derivatives; compare actual content as well as file hashes. Include
the sources nested in a split-screen/montage. Multiple layers of one continuous
shot are one occurrence, not an excuse to repeat it later. Preflight now checks
path, original ID, original/source hash and nested sources. Missing provenance
cannot establish that two pictures are distinct.
