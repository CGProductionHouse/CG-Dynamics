# Windows Premiere tool shortlist — 21 October 2026

This is a researched pilot list, **not an installation receipt**. Read-only machine inventory found Adobe Premiere **26.5.2** on the current Windows desk and no Dagger or OpenCurve installation in the standard CEP extension folders. The CGPH implementation lane is [issue #856](https://github.com/CGProductionHouse/CG-Dynamics/issues/856), with an owner-directed read-only inventory and bounded 4K pilot first. Each optional extension must preserve an editable Premiere master and a clean fallback. Check the actual Adobe build, Windows support, source/licence, any media upload, and a second workstation before claiming team deployment.

| Tool | Verified position | Useful task | Decision |
| --- | --- | --- | --- |
| [Premiere Time Remapping](https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-speed/change-clip-speed-and-duration-using-time-remapping.html), [Search/Media Intelligence](https://helpx.adobe.com/premiere/desktop/organize-media/file-organization/media-intelligence-and-search-panel.html), [audio fades](https://helpx.adobe.com/premiere/desktop/add-audio-effects/apply-audio-transitions/fade-in-or-fade-out-clip-audio.html), [Essential Sound ducking](https://helpx.adobe.com/premiere/desktop/add-audio-effects/adjust-volume-and-levels/automatically-duck-audio.html) | Included with Premiere | Native select, ramp, sound and mix baseline | Build recipes here first; no extra seat or missing-effect risk. |
| [Premiere modern effects/transitions/animations](https://helpx.adobe.com/premiere/desktop/add-video-effects/types-of-effects/effects.html), [Object Mask](https://helpx.adobe.com/premiere/desktop/add-video-effects/work-with-masks/object-masking.html), [single-word captions](https://helpx.adobe.com/premiere/desktop/add-text-images/insert-captions/create-single-word-captions.html) | Adobe says 90 modern effects are included at no extra cost; masking and captions are built in | Test native blur/transition, foreground title, kinetic caption before adding an extension | Object Mask's first use downloads models; verify result frame by frame. Adobe says Smooth masks are not supported in Team Projects and can be damaged by opening in 26.0, so test cross-editor project compatibility. |
| [Dagger](https://knightsoftheeditingtable.com/dagger) | Vendor says free; Premiere 2020+ and Windows supported | Faster effect/preset search and application | Candidate for one-machine timing/compatibility pilot; it speeds operations, not story choice. |
| [OpenCurve](https://github.com/fayewave/OpenCurve) | Creator's open-source project says free, Premiere 2020+, Mac/PC | Keyframe curve shaping for chosen title or motion effects | Candidate for isolated easing pilot; export/import curves could support staff consistency, but do not require it to reopen a project. |
| [ClipDeck](https://clipdeck.net/) | Free tier exists, but vendor says **Windows coming soon** | Asset launcher/library | Do not install or promise for current Windows desks. Revisit only after a released Windows version is verified. |
| [FXSeeker](https://fx-seeker.com/) | Vendor lists a paid licence | Effect/preset search | Not a free-plugin recommendation. Compare Dagger/native workflow before proposing spend. |
| [BeatEdit 2](https://aescripts.com/beatedit-for-premiere-pro/) | Paid optional tool already evaluated in #856 | Candidate music beat markers | No role in deciding best shot or story; use only if separately licensed. |

The tutorial mention of RSMB, a paid title pack, a “free SFX” link, or a trending song is not a licence. Keep rights evidence per project. An extension can save clicks while making a handoff worse if another editor lacks it; for each pilot, compare task time, result quality, export reliability, how it appears on a machine without the extension, and whether Premiere native controls remain editable.
