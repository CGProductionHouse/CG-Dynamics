1. A deterministic local scene graph owns composition, stable layer IDs, source provenance, manifests and isolated amendments.
2. Portable SVG is the complete interim editable document; Chrome locally renders a review PNG.
3. Photoshop 2026 is the preferred PSD finishing engine. UXP supports document creation, smart-object placement, live text layers, layer transforms and PSD saving. The checked-in `.psjs` beta must still pass a real Photoshop round trip before PSD is claimed as supported.
4. Image generation is optional for decorative assets only. It must not reconstruct real Red Oak food, people, products, venue or exact logos.

### Photoshop / UXP

UXP is the strongest installed professional path. Photoshop exposes real documents, layers, editable text, transforms, masks via the Imaging API, `batchPlay` for commands not yet in the DOM, and `Document.saveAs.psd`. Mutations must run in modal scope. Standalone `.psjs` scripts are supported in the installed versions and can later be reused inside a plugin.

The first beta uses a user-selected private job folder, avoiding full-disk plugin permission and all network access. It supports smart-object images, live text, rectangles and groups; unsupported vector paths/gradients remain explicit.

Official references:

- <https://developer.adobe.com/photoshop/uxp/ps_reference/classes/document/>
- <https://developer.adobe.com/photoshop/uxp/ps_reference/classes/layer/>
- <https://developer.adobe.com/photoshop/uxp/ps_reference/media/batchplay/>
- <https://developer.adobe.com/photoshop/uxp/ps_reference/media/uxpscripting/>
- <https://developer.adobe.com/uxp/guides/how-to/recipes/filesystem-operations/>

### Open-source segmentation and PSD writers

- `rembg` is mature as a wrapper, but model licences vary; the BRIA model needs a commercial agreement. It is not a safe default merely because the wrapper is MIT.
- Meta SAM 2 is Apache-2.0 but its official Windows guidance favours WSL and a Torch/CUDA stack. It is excessive for the initial photo-led poster proof and remains an optional future local mask engine.
- `ag-psd` can read/write many PSD structures but does not reliably redraw all text and warns about Photoshop compatibility. It is not preferred while real Photoshop/UXP is installed.

References:

- <https://github.com/danielgatis/rembg>
- <https://github.com/facebookresearch/sam2>
- <https://github.com/Agamnentzar/ag-psd>
