## 5. Caption standard

Core rule: **add; do not repeat**.

Read the artwork/video first. If it already contains the model, price, finance figure, headline, promotion, event date, branch or feature list, do not paraphrase those lines underneath it.

Add one useful second layer instead:
- who the vehicle suits;
- one real use case;
- one verified feature translated into buyer value;
- a test-drive or viewing reason;
- service/ownership relevance;
- a handover/customer moment;
- a staff/dealership moment;
- useful local context;
- a buyer question worth considering.

Default rhythm:
- concise to medium length;
- one clear commercial idea before the footer;
- short clean sentences for reels and fast visual posts;
- more technical detail only when it genuinely helps the buyer/owner;
- do not list every Human Auto service/division in every caption;
- if multiple options are requested, make them meaningfully different.
