# Nolan editing handoff in CG Dynamics

Open an assigned video from **Work → My Video Queue**, or use **Content →
Video Pipeline**. Open **Nolan editing handoff** and copy the prompt into
the company Nolan editing chat. It identifies one staff-only
record and the matching client, Content Run and video. Open the same staff
link to return to that video. Videos without a verified link to a saved
guideline remain visible on the board. Their handoff explains what is missing.

CG Dynamics owns the brief, assignment, production state and review links.
The client's existing OneDrive **Video Editing Library** holds the private
brand kit, media, approved edits and attributed feedback. Resolve the kit by
exact Dynamics client ID in the existing OneDrive registry. Check the saved
brand template first and consult Canva for missing or changed details. Record
the source, date and approval of any new brand fact in that kit. A brand
preference belongs to that client. Adopt a house rule only after a deliberate
decision. Follow the live library head in PR #910 when updating the guide link.
[Nolan start guide and shared technique library](https://github.com/CGProductionHouse/CG-Dynamics/pull/910)

Claude's shared transcript shows a useful workflow for graphics-heavy jobs.
Load brand rules and the previous cut before writing the brief. Plan the first
three seconds, on-screen wording and source in each timed scene. For a
website or app showcase, start with verified screens and check what can be
shown. Identify any crop or recreation. Put typography and device motion on a
single timeline with room for both. Inspect key frames before rendering and
check the actual MP4 and editable project before review. Save the feedback by
revision with the parts to keep and the parts to change. Carry confirmed
changes into the next edit. A contact sheet checks layout and readability.
Motion and sound need a full-speed review.

For a fair comparison, use the same internal brief, source screens, aspect
ratio and length for Claude and Nolan. Compare the first-three-second hook,
clarity on a phone, brand fidelity, meaningful motion across the cut and one
small revision that preserves the approved opening and ending. Include the
editable source and compare the exact review exports. A short browser-based
device-motion test is a useful candidate for this brief. The chosen renderer
stays with the existing Nolan production lane. Confirm the quality with the
actual cuts and record the outcome in the shared technique library.

Keep the deliverable, editorial and approval workflow in the existing
Pipeline. The handoff supplies IDs and a staff link for the connected editor
to retrieve current evidence. Scripts, footage links and review URLs stay in
their original systems. Idea feedback belongs to the guideline version.
Review of a finished edit belongs to the actual export and revision. Use the
existing project and review controls to record decisions.
