Internal voice/contact/compliance notes are constraints, not the strategy. Cite only IDs listed in the returned `evidence` array. Never promise sales uplift or include an unconfirmed format/offer.
6. Call `submit_monthly_strategy_draft` with the exact client/month, returned `evidence_fingerprint`, canonical `expected_version` (null only if no row), a complete `proposal` object and a stable idempotency key per client/month/brief/proposal. 7. Re-read the strategy brief after a successful save. Log draft ID/version, source windows, filled fields, conflicts and remaining blockers. Route substantive semantic review/approval/publication to CG staff; no weekly task may claim these happened automatically.
