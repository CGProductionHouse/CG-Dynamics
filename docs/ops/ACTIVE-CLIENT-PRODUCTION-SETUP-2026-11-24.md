## Generic cause and fix

Staff registration previously rejected real legacy names such as `VIDEO_1`
  because it demanded a two-digit number and concept suffix. It also required
  online media filing before a genuine internal export could be tracked.
The existing pure registration contract now preserves real numbered/unnumbered
legacy identities. A padded number or changed concept for the same numbered
client/month film shares a deterministic collision ID. Archived/history scans,
exact-client fences, lost-response recovery and readback remain mandatory.

An unfiled private edit/internal delivery requires its exact workstation and
matching absolute MP4 path, complete SHA, revision, responsible editor and HTTPS
handoff reference. Local paths are private receipt text, never URLs or publication
grants. Approved/client-delivered registration still requires the media link.

`register_existing_internal_video` reuses that SAME contract/table; it creates no
second tracker. It requires explicit company_admin context and the verified
connection's admin/manager role. Client/staff Projects cannot invoke it. It only
accepts private-edit/internal-delivery states, rejects arbitrary fields and never
performs approval, publication, file copying or schedule creation. Full result
receipts use the existing private MCP log, including both audit principals.
