# Social Poster Production Workflow

## Batch input

A poster batch must start from an exact client and a dated schedule/month. Retrieve or verify:

- exact client/sub-brand;
- current locations/branches relevant to the brief;
- month/season/local context;
- current service/product truth;
- approved brand colours, fonts and logo assets;
- client voice and content restrictions;
- recent Canva creative history;
- available OneDrive source media;
- recent usage history when Dynamics exposes it.

## Media selection

1. Resolve the exact client's canonical OneDrive folder. Do not fuzzy-match before selecting or mutating files.
2. Prefer edited/source-ready folders where provided; fall back to broader client photos only when necessary.
3. Review multiple candidate images rather than taking the first filename match.
4. Reject irrelevant/stale people, products, premises or services based on current client truth.
5. Avoid exact image reuse within the same batch.
6. When possible, prefer a fresh shoot or previously unused-looking source over a historically common hero image.
7. Store the canonical OneDrive item ID/URL used by the final design so Dynamics can build a permanent usage ledger.

## Human photo treatment

Allowed by default:

- exposure/white-balance correction;
- contrast/highlight/shadow balancing;
- colour grading;
- crop/straighten/lens correction;
- noise/sharpness/clarity adjustment;
- dust/sensor cleanup;
- temporary blemish or obviously transient scratch/redness cleanup.

Not allowed without explicit client/user instruction:

- changing nose/eyes/mouth/face shape;
- changing body shape;
- removing permanent beauty marks or identifying traits;
- changing age, skin identity or ethnicity;
- replacing the real person with a generated likeness;
- generating an employee who never existed.

## Creative-history check

Before design:

- inspect the latest Canva pages for the client/sub-brand;
- note recurring layout devices, headline structures, image treatments and subjects;
- preserve brand grammar but avoid cloning a previous page;
- reject a concept when the immediate reaction is 'this looks like June again'.

Canva is creative history, not the long-term usage ledger. Dynamics should become the canonical record of what media/topic/concept was actually used and when.

## Design standard

A batch should feel related without being three variants of one template. Vary intentionally across:

- image scale/crop;
- light vs dark field;
- typography placement;
- density and negative space;
- subject (people / place / product / service / community);
- emotional role (practical / human / seasonal / playful / premium).

Brand consistency comes from exact assets, typography, palette, spacing discipline and voice — not from repeating one layout.

## Logo and font handling

- Logos are imported as exact files, never regenerated.
- Partner logos should also be exact files when they appear as graphic elements.
- If a logo is visible naturally inside a source photograph, do not retouch/recreate it unless the job requires it.
- Use the client's specified font family. A prototype rendered in a substitute font must be explicitly labelled a prototype and corrected before production delivery.

## QA checklist before CA/internal review

- [ ] all factual claims verified against current client truth;
- [ ] exact logo assets used / no logo hallucination;
- [ ] exact client photographs with provenance recorded;
- [ ] no exact photo repeated in the batch;
- [ ] no person identity altered;
- [ ] no branch photo presented as a different branch;
- [ ] current month/local/season context is appropriate;
- [ ] recent Canva subjects/headlines/layouts checked;
- [ ] design remains readable at 1080x1350 phone size;
- [ ] spelling matches client/South African standard;
- [ ] no accidental stock/AI-looking client representation;
- [ ] final limitations disclosed before approval.

## Canva handoff

Design may be produced outside Canva when that gives materially stronger creative control. After internal approval:

1. import the approved flat design into Canva for editable conversion/handoff where practical;
2. replace any prototype font with the exact Canva/client font;
3. use exact logo assets in Canva if the prototype could not embed them;
4. link the Canva design/page back to the exact Dynamics schedule item;
5. retain OneDrive source IDs so later runs know what was used.
