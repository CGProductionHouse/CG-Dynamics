# Creative Strategy Gate for Social Posters

## Purpose

No static poster should move into design because 'we need three posts this month'. The system must first establish why the post exists, who it is for, what it should make them think/feel/do, and what creative mechanism gives the message a reason to be noticed.

This gate adapts the existing CG Dynamics marketing research into a practical social-poster brief.

## Required brief before design

```text
Business objective
Buying situation / real moment
Audience
Audience tension / need / desire
Primary content role
Single-minded proposition
Proof / reason to believe
Desired emotional response
Desired action / memory
Distinctive brand assets to use
Current month / place relevance
Creative mechanism
Headline candidates
Photo/media requirements
Recent concepts to avoid
```

## Content roles

Every poster has one primary role:

- activation / direct response;
- brand building / memory;
- trust / proof;
- product or service education;
- convenience / reminder;
- local relevance / community;
- entertainment / humour;
- seasonal moment;
- recruitment / announcement;
- event attendance;
- reputation / reassurance.

Secondary benefits are allowed, but the poster must have one primary job.

## Headline test

A headline is rejected if it is:

- abstract without a concrete meaning;
- interchangeable with another client;
- generic AI language such as 'elevate your experience', 'where quality meets...', 'your trusted partner', or vague statements about being 'human';
- merely descriptive of the photo;
- a slogan with no relationship to the audience's real moment;
- too long or too small to work on a phone;
- clever only after explanation;
- unsupported by the rest of the poster.

A headline should ideally do at least one of these:

- recognise a real audience problem or moment;
- create relevant curiosity;
- state a desirable outcome;
- expose a useful contrast or tension;
- lead with proof;
- make a locally recognisable observation;
- make the audience smile because it feels true;
- make an offer/service immediately meaningful.

## Human-emotion check

Before approving copy, state the intended emotional result in plain language.

Examples:

- 'I know exactly what that feels like.'
- 'That is useful; I should remember this place.'
- 'That made me hungry.'
- 'That is clever.'
- 'I trust these people.'
- 'That solves an annoying little problem.'
- 'That feels like Bloem, not generic national copy.'
- 'I want to show this to someone.'

If the intended result is only 'sounds premium', the brief is not strong enough.

## Creative-mechanism rule

The design mechanism is selected after the strategy, not before it. Possible mechanisms include:

- photographic editorial cover;
- cutout subject breaking the grid;
- dynamic gradient/light treatment;
- oversized type interacting with subject;
- product macro / scale play;
- sticker / handwritten annotation;
- bold price/offer architecture;
- visual contradiction;
- before/after or comparison;
- map/location idea;
- magazine/newspaper-inspired advert;
- retro local advertising reference;
- collage;
- photographic sequence;
- graphic iconography;
- restrained premium minimalism when the message genuinely benefits from it.

A batch must not default to the same mechanism with different images.

## Monthly batch rule

Before creating a month:

1. review the prior month as a grid;
2. note headline positions, light/dark balance, recurring faces, products, branches and mechanisms;
3. review any available performance and client feedback;
4. decide the new month's visual rhythm as a set;
5. ensure each poster works alone and the grid does not reveal one reused template.

## Mobile-first QA

Review at phone size, not only zoomed-in desktop size.

- the hook/headline should be legible quickly;
- essential information cannot rely on tiny footer copy;
- the visual focal point must survive the Instagram feed crop/context;
- important text must avoid platform UI/safe-zone issues where relevant;
- logo must be attributable without dominating every design;
- decorative effects must increase attention/hierarchy rather than become noise.

## Evidence and learning

Monthly strategy should eventually incorporate Dynamics performance data and approval history, including:

- posts the client asked to boost;
- comments/saves/shares where available;
- meaningful audience responses;
- paid support/spend context;
- client requested repeats;
- rejected concepts;
- content that created enquiries or other verified outcomes.

Do not optimise the system solely for likes/views. Use performance evidence in the context of the poster's primary objective and the broader brand strategy.
