# Staff SOP — monthly designed-poster production

Last updated: 2026-09-09

## Goal

Give CG staff one repeatable, dummy-proof process for producing a whole month's Designed Posters (`DP`) whether the visual creative is generated by ChatGPT or designed manually.

AI is optional. The strategy, naming, source preparation, freshness, approval and tracking discipline is not.

The expected output standard is **above normal production standard**, not “good enough because AI was fast.”

## Core rule

Never begin by opening Canva and designing “something” because a poster slot exists.

Begin from the exact client/month/package in CG Dynamics and create a deliberate monthly marketing mix.

## Required truth before work starts

- exact client + immutable Dynamics client ID;
- exact month;
- exact numbered package slots (`DP1`, `DP2`, etc.);
- exact canonical client short code;
- relevant brand scope/sub-brand and branch/location where needed;
- current client strategy/restrictions;
- previous strategy/creative history;
- recent source/person/product/service usage;
- canonical OneDrive media;
- correct brand-scope Canva history;
- relevant performance/client feedback where available.

## Phase 0 — first-client historical bootstrap

Run once when a client enters the system.

1. Separate the client's different brand scopes before auditing Canva.
2. Inspect `POSTED / SCHEDULED` and useful older approved Canva work.
3. Record used media, visible people, products/services, branches, hooks and creative mechanisms.
4. Match historic poster media back to canonical OneDrive using exact IDs/hashes/perceptual similarity/visual review where possible.
5. Record unresolved historic media honestly as legacy/unresolved.
6. Seed the usage/freshness ledger and style-reference sets.

After this bootstrap, every new month must continue from recorded state. Do not repeat the full audit each month.

## Phase 1 — monthly creative planning

A staff member may begin with a short instruction or voice note, e.g.:

> We need November Piek Group Engen posters. I was thinking warmer weather and people making more plans.

The planning ChatGPT then:

1. resolves the exact Dynamics month/package;
2. reads prior strategy, approvals/rejections and client feedback;
3. reads relevant performance/boost history where available;
4. inspects the correct brand-scope Canva history;
5. inspects media/subject/concept usage history;
6. inspects fresh real OneDrive media;
7. researches current local/seasonal/category context where useful;
8. decides the month's marketing mix before design;
9. assigns every concept to an exact DP slot;
10. completes the Creative Strategy Gate for each DP;
11. selects fresh source media;
12. prepares the source and monthly generation pack.

Every poster needs a reason to exist. Not every poster needs to become a giant campaign.

## Phase 2 — canonical identity

Designed poster:

`YYYY_MM_CLIENT_DP_XX`

Example:

`2026_11_PIEK_DP_01`

- `XX` is the zero-padded Dynamics instance number.
- `monthly_deliverables.id` remains the immutable database identity.
- sub-brand/branch stays metadata and does not replace the client code.

Example metadata:

```text
stable_production_id = 2026_11_PIEK_DP_01
brand_scope = ENGEN
branch_location = NORTHRIDGE
```

Optional descriptive suffix:

`2026_11_PIEK_DP_01__ENGEN_SUMMER_PLANS.png`

Staff should not manually invent canonical IDs once Dynamics can derive them.

## Phase 3 — source selection / freshness

Before selecting media, check all of these separately:

- exact image used before?
- crop/re-export of same source used?
- near-identical burst/shoot/angle used?
- same visible person used too often/recently?
- same product/service/topic overused?
- same branch/location overrepresented?
- same headline/concept repeated?
- same creative mechanism/layout family repeated?

Prefer fresh real client-owned media.

Reuse is allowed only with an explicit reason: client request, campaign continuity, seasonal relevance, meaningful time separation, unique proof value or a genuinely different reinterpretation.

## Phase 4 — professionally prepare selected source

Raw/original remains in the client's normal `Photos` hierarchy.

Create a non-destructive production derivative in:

`Posters/<YYYY>/<YYYY_MM_MON>/01_SOURCE_EDITED/`

Example:

`2026_11_PIEK_DP_01__SRC_EDITED_01.png`

A file in `SOURCE_EDITED` must already look like something a professional designer/photographer is happy to design with.

Allowed photographer-grade work:

- exposure/highlight/shadow recovery;
- white balance/colour correction;
- tasteful contrast/clarity/sharpness;
- crop/straighten;
- lens/perspective correction where appropriate;
- temporary blemish/fresh scratch/redness cleanup;
- cutout/background cleanup when required by the concept.

Never change identity-defining human features. Preserve permanent marks/features and the person's day-to-day appearance.

### Preferred tool split

- Use Adobe/Photoshop-style non-generative tools for fidelity-sensitive real photography.
- Do not ask the image generator to “beautify” or recreate a real person's face.
- If a cutout is required, make the real source/cutout available as an exact input layer/reference.

## Phase 5 — build the monthly Chat Pack

Prepare the planned month as one batch where practical.

`02_CHAT_PACK/` contains:

```text
CHAT_ATTACH/
PROMPT.txt
MANIFEST.csv
<YYYY_MM_CLIENT>_CHAT_PACK_vNN.zip
```

### `CHAT_ATTACH` contains

- exact professionally edited source image(s), named by DP ID;
- exact client/partner logos/assets;
- only the correct brand-scope style-reference screenshots;
- optional supporting visual reference that is genuinely needed.

Do not mix Piek corporate / Engen / Sasol / Get Together references in one style feed.

Use approximately 3–6 deliberate style references per brand scope where practical. Enough to teach visual grammar; not enough to encourage copying one historical layout.

### Manifest contract

Every DP row must make the mapping unambiguous, for example:

```text
stable_production_id
monthly_deliverable_id
brand_scope
branch_location
primary_role
audience_moment
proposition
intended_emotion
desired_action
headline_direction
source_file_1
source_file_2
logo_asset
style_reference_scope
creative_mechanism
recent_avoidance_notes
reuse_reason
```

If ten posters are generated together, the generator must never have to guess which photo belongs to which DP.

## Phase 6 — Wave 1 generation

Use normal ChatGPT browser chat with the internal image generator as the high-design composition engine.

1. attach all required `CHAT_ATTACH` images for the planned batch;
2. paste/use the supplied exact monthly prompt;
3. generate the planned DPs;
4. save viable first candidates into `03_WAVE_1` using exact stable IDs.

Candidate example:

`2026_11_PIEK_DP_01__W1_V01.png`

### Generator's job

The generator is encouraged to have visual fun with:

- composition;
- gradients/light;
- depth;
- masking/cutout interaction;
- texture;
- scale;
- visual hierarchy;
- collage/effects;
- editorial/advertising mechanisms.

It is not trusted as the final source of truth for:

- exact logo geometry;
- exact font rendering;
- real-person identity reconstruction;
- factual product/client details not supplied in the pack.

If generated text/logo treatment looks even slightly fake/distorted, the design can still pass **creative** review if the underlying composition is excellent and the incorrect production element can be cleanly replaced. It cannot pass final production approval until corrected.

## Phase 7 — Wave 1 internal QA

Wave 1 is internal CG material, never automatic client-ready output.

Review each poster at realistic phone size and the whole batch together as an Instagram grid.

### Individual creative QA

Ask:

- clear useful marketing job?
- headline instantly meaningful?
- visual and words strengthen each other?
- strong focal hierarchy?
- source/person remains believable and correct?
- feels designed, not generated/template assembled?
- worth publishing even if the package did not force a DP?

### Batch/grid QA

Check variation across:

- headline position;
- crop/scale;
- light vs dark balance;
- subject/person/product/branch;
- negative space;
- creative mechanism;
- type behaviour;
- gradients/effects/texture;
- density/minimalism.

The posters should look related by brand, not related by template.

## Phase 8 — amendment decision tree

Do **not** automatically say “edit poster 3” against the same generated bitmap.

First classify the failure.

### A — production correction: do not regenerate

Examples:

- exact logo;
- typo/copy correction;
- exact font;
- font size/spacing;
- exact colour;
- margin/alignment;
- small element nudge.

**Action:** Canva/Adobe production correction.

### B — source-photo correction: return to original source

Examples:

- crop;
- exposure/colour;
- temporary blemish;
- cutout/background cleanup;
- fidelity concern with a real person/product.

**Action:** edit the original selected source non-generatively and recompose only if needed.

### C — creative concept/composition failure: restart that DP cleanly

Examples:

- boring/generic;
- AI/template feeling;
- wrong visual hierarchy;
- wrong emotion;
- headline strategy weak;
- composition fundamentally misses the brief.

**Action:**

1. keep all accepted DP IDs locked;
2. return to the planning/strategy record for only the failed DP;
3. write a **correction delta** explaining what failed and what must be different;
4. reattach the exact original edited source(s), exact logo/assets and relevant style refs;
5. include the original strategy + correction delta;
6. generate a fresh new Wave candidate from source.

Example:

`2026_11_PIEK_DP_03__W2_V01.png`

Do not use the failed generated poster as the sole new source. This avoids generative decay and stops real photography becoming progressively fake.

### D — minor visual effect correction

If Canva/Adobe can fix it cleanly, use that route. Do not regenerate a whole person/photo because a glow or gradient is slightly wrong.

## Staff prompt for a failed poster

Use a clean restart instruction conceptually like:

> Regenerate only `2026_11_PIEK_DP_03` from its original supplied edited source and the same brand-reference pack. Keep the original strategy except for this correction delta: [specific failure and required change]. Do not base the new design on the failed generated bitmap. Create a genuinely new composition and keep the real source person's/product's identity unchanged.

The monthly pack should eventually generate this instruction automatically.

## Phase 9 — production finish

Once the **creative idea** is approved internally, move through exact production finishing.

Use Canva/Adobe for:

- exact Sora/Inter or client-approved typography;
- exact original client/partner logos;
- clean text replacement where generated lettering is imperfect;
- exact brand colours;
- safe photo compositing/correction;
- editable staff handoff;
- final platform/export sizes.

Canva image-to-design / Magic Layers may be tested to turn a strong flat generated poster into editable layers. Use it as a finishing route, not as the primary art director.

## Phase 10 — approval and Dynamics linkage

Approved creative moves to `05_APPROVED`; production/editable handoff is tracked in `06_CANVA_HANDOFF`.

The final DP resolves to the exact existing monthly deliverable.

Record/retain:

- `monthly_deliverable_id`;
- stable production ID;
- client/month/code/instance;
- brand scope + branch/location;
- scheduled date;
- strategy version;
- original + edited source OneDrive IDs;
- exact/near-duplicate/shoot usage state;
- people/product/service/concept/mechanism tags;
- reuse reason;
- candidate/amendment history;
- exact Canva design + page;
- approval state;
- schedule/publish reference;
- later performance/learning.

Do not create a second social calendar. `monthly_deliverables` remains schedule truth.

## Phase 11 — after publishing / next month

Before next month's planning, read:

- what was planned and why;
- approved/rejected concepts;
- amendment reasons;
- media/person/product/service/branch usage;
- Canva final creative;
- client feedback;
- items the client asked to boost;
- relevant Meta/platform performance;
- enquiries/verified outcomes where available;
- current season/context.

Continue from that state. Do not start over.

## Minimum rejection gate

Reject or hold any poster if one of these is true:

- weak/generic/meaningless headline;
- no clear audience/buying moment/marketing purpose;
- wrong or unsupported client truth;
- wrong/recreated logo in final production;
- identity-altered real person;
- unreadable phone typography;
- repeated photo/person/service/concept without reason;
- looks like Word/PowerPoint/stock Canva;
- obviously AI-generated text/logo texture remains in final;
- same template skeleton repeated across month;
- grid is monotonous or visually clashes;
- concept relies on effects to hide weak strategy;
- output is below CG Production House's own visual standard.

The process is working only when strong, client-specific work becomes repeatable rather than occasional.
