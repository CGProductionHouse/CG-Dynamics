# Planner Add Task Position — Launch UX Decision

Last updated: 28 July 2026
Status: launch-critical product decision

## Decision

The Planner `Add task` control must appear at the top of each bucket/column, directly under the bucket heading.

Staff must not need to scroll to the bottom of a long column before they can create a new task.

## Required behaviour

- Keep task creation immediately accessible at the top of every visible Planner column.
- Opening the control should allow a fast title-first add flow.
- Additional details may expand below or open the normal task drawer.
- The control must remain practical on desktop and mobile.
- If a secondary add control is retained at the bottom for convenience, the top control remains the primary one.
- Do not create duplicate tasks if the quick-add flow is submitted more than once.
- New tasks must use the currently selected plan and bucket.
