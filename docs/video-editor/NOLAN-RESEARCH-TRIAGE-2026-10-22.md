## Decision in one minute

**Stay with Premiere as the editable 4K master.** Nolan already has TWO locally demonstrated routes: a bounded DutchErwin CEP bridge for exposed AE titles/font/size/colour and rendering, and a separately installed leancoderkavy UXP 1.24.3 bridge for native clip clones/effects/keyframes/save. The isolated UXP MCP was not made the default and was stopped at its last documented handoff. Read **live** #862 before adopting any status below. Neither the catalog of 283/530 tools nor installation proves whole-editor autonomy. The two transports lack a shared write lock; **never dispatch concurrent writers on the same project**. Existing issue/PR owns fixes, activation and creative deliverables.

**Highest-value new research lead:** *eyes for the editor*, not another editing-engine fork. [Jumper for Premiere agents](https://getjumper.io/ai-agents/premiere-pro) provides local visual/speech/person search through MCP and can return selects/sequence candidates to Premiere. It advertises search across analyzed media with metadata/timecodes instead of footage upload, with local analysis. Cost/plan, exact Windows build and 4K source/sequence handoff remain unverified. It complements rather than replaces editing MCP. **No installation/approval from this document.**

**Second lead:** Adobe's **built-in Media Intelligence** and Media Encoder preanalysis. Adobe confirms local visual search, transcript/metadata search, cached sidecars and no media upload. Its built-in Search UI is **not automatically available to Nolan's agent**; Jumper's claims about competing search are vendor claims. Sidecar storage beside media may help preserve analysis between office computers later, but **no migration project now**.

**Creative AI:** [Higgsfield's official Premiere plugin](https://higgsfield.ai/plugins/premiere-pro) actually exists: Generate Video/Image, Reframe, Remove Background, Draw-to-Edit, Upscale and prompt editing. Windows support and Premiere 2025+ are advertised. Processing is on Higgsfield servers; credits/subscription and client media permissions matter. Its **generation MCP** is not a proven general Premiere timeline-control MCP. Generated clips/alpha media do not substitute for native editable MOGRT/keyframes. **Do not buy, install or upload any client clip by default.**

**CapCut:** valuable *secondary* tool for short-form experimentation and simple rapid beat-sync, but it does not yet justify moving the canonical 4K Premiere workflow or engineering a second full editor. Official [Auto Cut](https://www.capcut.com/help/auto-cut-in-capcut) is advertised on desktop/mobile and can target beats, pauses or script; region/version availability varies. Unofficial CapCut draft/MCP libraries manipulate private `draft_content.json` formats that may change by version and sometimes require manual export. This makes them an isolated optional research lane, **not** a production Nolan dependency.

## High-confidence shortcuts / important limits

1. **Stop researching catalog sizes.** Instead request named operations with exact supported host version, a known-safe sequence duplicate and *readback plus a real frame/audio render*. A plugin's marketing video is not an installed capability.
2. **Frame-based creative decisions are more valuable than bulk flashy effects:** identify action apex, shot scale/direction, line-of-action, perceived camera motion, audio attack and intended emotional release. A jump cut that lands on the actual golf impact can outperform an artificial flash. See [creative selection playbook](NOLAN-CREATIVE-DECISION-SYSTEM.md).
3. **Do not assume an exposed speed tool works.** The [current leancoderkavy README](https://github.com/leancoderkavy/premiere-pro-mcp) explicitly marks scripted timeline speed writes unavailable on Premiere 26.3 despite listed tool names. Existing native interpretation 50→25 in #862 is a uniform slowdown **not** a variable ramp, and can affect other instances.
4. **Avoid silent cloud uploads:** Adobe Media Intelligence + Jumper vendor local indexing are distinct from Higgsfield and Firefly cloud generation. All new providers require client/source permission, per-use costs, terms, footage rights and processing location review before passing client files.
5. **Treat published plugin pages as dated claims:** Higgsfield's [central plugin page](https://higgsfield.ai/plugins/premiere-pro) describes a native Windows .msi and Premiere 2025+; its [help article](https://higgsfield.ai/creator-hub/help-center/integrations/external-integrations-higgsfield) describes a ZXP installer and Premiere 2024+. Don't blindly follow one route without checking the current specific binary/manifest.
6. **CapCut is not a free-to-automate Premiere:** Official desktop Auto Cut is a user-facing app feature. Unofficial draft-editing repositories are *not* evidence of supported native CapCut automation, preserved client fonts/licences or dependable unattended renders.
7. **Remote second-computer goal:** preserve dependency inventory, source paths, templates/fonts and proven recipes *as work is performed*, but **do not build a workstation installer/migration package now**. Only portable documentation for future, not current scope.
8. **Personal creative-learning loop:** each successful client-approved technique gets a selector (“use when / avoid when”), exact native implementation, before/after evidence and provenance. A tutorial observed visually is **discovered**, not **mastered**. Feedback must not be misinterpreted as a universal law.
