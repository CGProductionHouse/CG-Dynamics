## A modern, simple CG motion language

Six **CG-owned generic reusable ideas** (not client-specific branding):
1. **Kinetic brand hook**: logo/recognition cue + one readable statement, animated by a meaningful visual action, not generic title presets.
2. **Wheel/flow explainer**: radial line/icon/category rotation revealing a logical sequence; each spoke is an *approved service* rather than decoration. Can use native AE shape/rotation keys or coded Motion Canvas for difficult timing.
3. **Animated proof card**: photo/doc/product details slide/scale under transparent graphic; data values from an *approved, sourced* claim; no fake chart.
4. **Typography rhythm**: source-linked footage/poster/photo + large word/number, early brand signifier, fast motion/contrast then meaningful hold. Readable at phone size.
5. **Logo and CTA signature**: 2–3 seconds, consistent client-approved brand motion/sound, editable contact/website and approved microcopy; premium not cartoon swoosh.
6. **Material reveal**: reuse a real image from an *owned* Canva poster as layered texture or draw-on diagram, keeping words/colors as editable new graphic (unless client explicitly accepts baked export).

**Avoid the Renderforest failure mode:** do not fill films with the same generic template slideshow, 3D logo spinning for no reason, stock that doesn't match local buyers, or 12 things flying into frame. A strong concept + selective motion and sound produces freshness.

## Specific Adobe template features already documented, but NOT yet verified by Nolan

- [**Media replacement MOGRT**](https://helpx.adobe.com/after-effects/desktop/motion-graphics/work-with-motion-graphics-templates/replace-media-motion-graphics-templates.html): replace logo, video clip, photo while retaining the animation; usable for broker categories, product photos, moving pictograms and client-specific brands.
- [**Data-driven MOGRT**](https://helpx.adobe.com/premiere/desktop/add-text-images/use-motion-graphics-templates/use-data-driven-motion-graphics-templates.html): author text/colour/numeric data controls for repeatable explainer stats; **does not verify source claim**. Use client-approved figures only.
- [**Premiere-created graphics export](https://helpx.adobe.com/premiere/desktop/add-text-images/insert-images-and-graphics/export-graphic-as-a-motion-graphics-template.html): a native Premiere shape/text/keyframe graphic can itself be exported as a MOGRT for future re-use; not equivalent to re-exporting an After Effects-created MOGRT.
- [**Adobe Library / folder organisation**](https://helpx.adobe.com/premiere/desktop/add-text-images/use-motion-graphics-templates/organize-motion-graphics-templates.html): local folders or exact-client library for reusable clips, different from CG Dynamics authoritative Brand Hub folders and approval state.

All are product docs: **do not claim** Nolan can yet call media replacement or author data-driven mogrts via current MCP 19-tool CEP or experimental 1.24.3 UXP route.

## Free stock and rights

- [Pexels](https://www.pexels.com/legal-pages/license/): commercial usage permitted and free, but avoid identifiable people's implied endorsements and brand marks. A stock business consultation is **illustrative**, not a client's actual customer.
- [Mixkit](https://mixkit.co/license/): confirm an individual clip is licensed for commercial use; “restricted licence” media cannot be assumed advertising safe.
- [Canva license](https://www.canva.com/policies/content-license-agreement/): a Canva Pro *element* may not be downloaded/reused as standalone reusable asset outside Canva simply because CG has a paid Canva account. Full designs for ads may be permitted; client-owned original artwork is preferred for transferable graphics.
- [TikTok Commercial Music Library](https://ads.tiktok.com/help/article/commercial-music-library): free for *TikTok commercial posts*, **not** a blanket transferable music licence for Instagram/Facebook/other platforms; use licensed CG score or platform-specific separately cleared sound.

## Measure if a technique is worth including in Nolan

An eventual, separately owner-approved short, 4K original-linked demo in a real client context:
- owner/client already has a lawful, cleared brand source and marketing message; compare one native MOGRT and one **Motion Canvas** code-scene (if actual gap);
- test the same **animation quality** (readability, safe area, anticipation/reveal, rhythm, true/fake information, brand recognisability), not simply two file decode passes;
- report 1st render time + number of revisions + model tokens, the final editable project/source asset, graphics dependency/future desktop implications and after-effects operator work;
- qualify that a TypeScript animated image sequence is rendered/baked **in Premiere** but source-editable in the code project. If user requires native editable graphics, use MOGRT or reconstruct critical fields in Premiere.
- No added plugin or engine from this doc and **no user or client credits spent**.
