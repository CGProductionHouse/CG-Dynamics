The real lens location is tracked frame by frame on edge images using a local template from source 1.00 s. Detected centres move from x≈513 to 445, with y 368–371. The lowest normalized match score is **0.158**, so this is a narrow same-shot tracker with a bounded search/centre check, not a robust general lens detector. The mask starts within the dark rim and expands into a crop taken entirely from the current frame's **lens interior**. This crop avoids inventing a second book image and, after an initial failed render, avoids a visible *second lens rim* inside the opening. A source-specific HSV/region hand matte is scaled with the same camera push and composited above the opening; a protected 0.65 s frame retains the lower finger along the right/bottom edge where the unprotected version replaces it with page texture. The hand then leaves through the frame edge as the zoom completes. Every frame contains `STOCK PRACTICE`.

All three MP4s fully decode with 36 video frames and no audio. The first eight **output** frames are unchanged by the transition logic; from output frame 25 onward the plain push and opening use the same cropped picture, though separately encoded post-transition frames are **not pixel identical** (decoded SSIM 0.992841). This is technical preservation evidence, not an aesthetic preference. Local full-size frames at 0.55, 0.65 and 0.80 s were inspected; the earlier doubled-rim version was rejected and replaced. The current aperture still has a soft dark rim remnant near the left frame edge around 0.80 s, and the enlarging 720p interior text becomes visibly soft. Normal-speed playback, physical-phone crop, semantic book-text rights and a genuinely matched *second* shot have not been accepted. No soundtrack was chosen for this silent proof.

**Transfer rule:** use a physical opening only when its inner boundary can be tracked, its near-camera hand/rim stays in front until it exits a frame edge, and the incoming shot has a real causal connection and adequate source resolution. Compare with an ordinary push/cut; reject the mask if it creates duplicated rims, swallows a foreground object or softens the hero action. A boxing glove/rope crossing would need its **own** tracked foreground matte and truthful event continuity; this book-specific colour key is not a Fight Night mask preset. Keep the skill at `code works locally / visual review pending`, not mastered.
