## Decoded and visual result

All four H.264 outputs fully decode to 60 frames at the source frame rate and dimensions. All 59 adjacent pairs change in each. The three treatment outputs match the plain output pixel for pixel through frame 31; each changes all 28 later frames. Before encoding, the maximum difference outside the glyph alpha is zero. At decoded frame 44, outside-glyph mean absolute difference against plain is 0.838–0.854 RGB levels, so **strict encoded zero spill fails** because of chroma/codec coupling. Full frames 24/31/32/38/44/59, ordered contacts and a 180×320 reduction were inspected.

R01's pitting reads as dirt and draws attention to the material, so it is rejected. R02 has a cleaner internal edge at full size, but its bevel has little advantage at the reduced comparison and the flat gold word reads most evenly. The title stays above the fighters in sampled frames; this is a bounded layout result, not a normal-speed human viewing or physical-phone pass. The main learning is to start with a flat readable title and justify material only when brand/story warrants it; no generic gold look is approved for CG clients.
