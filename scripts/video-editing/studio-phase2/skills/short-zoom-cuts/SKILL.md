# Short zoom cuts — visually sampled, untested

**Lifecycle:** [owner's Miracamp reference](https://www.tiktok.com/@miracampschool/video/7504014296779590935) sampled at about 1, 15 and 23 s → original footage/render pending → mastered **NO**.

The tutorial shows multiple adjacent three-frame Premiere clips, Transform scale keyframes and an on-screen `SHUTTER ANGLE=200` instruction for motion blur. Its caption adds ease in/out and copying the treatment to the following clips. This is an example recipe, not an endorsed duration or shutter setting for every source frame rate.

The [26 October source screen](../../SHORT-ZOOM-SOURCE-SCREEN-20261026.md) rejects a landscape golf source for losing player/flag geography in a portrait fill and a portrait coffee pour for lacking an action peak or distinct second view. Neither merits a zoom just because the tutorial shows a Transform recipe. Select an action before touching scale controls; retain the plain cut as the control.

Select shots that share a subject position or an intentional directional path. Cut an original disposable sequence, try three frames at the project fps, and compare against a longer cut at phone size. Keyframe scale around the actual focal point; ease and blur should hide discontinuity without making the subject unreadable. Watch for repeated frames, warped optical flow, edge exposure and flashes. Use existing native Transform controls for editable handover, or the established FFmpeg rendering path for a non-editable study.

Do not add a plugin for this effect. The first [source screen](../../MOTION-SOURCE-SCREEN.md) rejected the available same-person coffee angles because the action jumps between wide and close frames; a faster zoom would emphasize the mismatch. No original local output, precise blur comparison or sound audition has been completed.
