# Fight vertical action framing

**Lifecycle:** [stock fill-versus-fit A/B](../../FIGHT-VERTICAL-FRAMING-STUDY.md) shows a hero-shot framing failure → [three portrait-source screen and plain/tighter/protected-less-tight A/B](../../FIGHT-PORTRAIT-FRAMING-SCREEN-20261029.md) rejects added crop → actual event/phone review pending → mastered **NO**.

For each candidate hit, confirm the target, striker, contact and immediate result in the original source. Test the final aspect ratio early. A frame-filling crop is useful only while those elements remain readable through the moving shot; one good still is insufficient. A full-width fit may preserve evidence but shrink the action too far for a phone.

Compare the simple fill and fit controls before trying a tracked crop, composite, zoom or graphic border. If both fail, select a closer or portrait camera angle or use the wide source for geography rather than hero impact. Never cut away the contact point and compensate with a sound effect. Keep a second reviewer and original source timecode in the edit log.

The first proof tests one 16:9 stock shot only. The [later portrait screen](../../FIGHT-PORTRAIT-FRAMING-SCREEN-20261029.md) shows that an upright source can still put both fighters at the borders. Its later 1.25× and 1.08× crop variants decoded and protected the same opening, but each loses more context than the plain full portrait; both are rejected. Neither study establishes a good final layout, event contact, normal-speed readability or a client-approved end product.
