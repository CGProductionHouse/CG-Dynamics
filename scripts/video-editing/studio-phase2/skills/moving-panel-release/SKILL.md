# Moving-panel release — source-bound candidate

The owner reference is [`@_vibszyy` 2026 Moments](https://www.tiktok.com/@_vibszyy/video/7683518388668337428). Sampled playback shows unequal moving panels and small year/moments labels resolving to wider picture. The exact CapCut-labelled post did not expose an editable template timeline; reference sound was muted. The [4 November study](../../EHRLICH-TWO-CAPCUT-REFERENCE-STUDIES-20261104.md) is the evidence, not a claim of template replication.

## Construction

1. Choose **three distinct actions** that belong in the film, then identify the single action the panes will resolve into. Verify source rights, relevant public use and useful source timecodes before effect work.
2. Crop each source to fill its own aperture without changing aspect ratio. Use the same source time on both sides of a pane-to-full-frame release. Never hide the meaningful action behind a panel gutter.
3. Make a sequential plain control using those exact sources and title. The effect only earns its place if simultaneous anticipation improves the hook and the reveal lands on visible action.
4. Place the type inside the actual brand system and phone safe area. If title motion masks the action, move the text or shot, not just its colour.
5. Keep sound on separable stems. Align a licensed transition cue's **measured actual peak** with the picture release, and retain useful source ambience where cleared. Technical alignment does not prove that it sounds good.

## Tested result and failure

The EHP proof recipe `../../ehrlich-november/reference_proofs_20261104.py` produces a 3 s portrait plain/panel pair from hash-verified original hands/knife footage and licensed fire. The first panel layout stretched imagery and was rejected. A crop-to-fill repair fixed geometry. The first full-frame select landed on static raw meat; moving the knife select to 5.25 s placed visible cutting beneath the release and title. The first audio trim removed the cue's strongest event; the repaired decoded AAC peak was 1.52 s for a 1.50 s release. These are bounded picture and timing results, not a final client sound review. Private derivatives and licensed assets are not in Git.

## Use gate

Use when the film genuinely has multiple relevant actions and the release clarifies their relationship. Reject when the full-frame destination is less interesting than the panes, an object is stretched or cropped out, or a plain cut communicates the action sooner. Before client delivery, review the whole film at normal speed with sound on headphones/speakers and a phone-sized frame, then verify licensed audio, brand, source/public-use context and staff handover. Do not call this native CapCut template mastery.
