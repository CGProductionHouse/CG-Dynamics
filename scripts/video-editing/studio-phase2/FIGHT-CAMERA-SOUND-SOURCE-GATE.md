# Fight camera sound: source candidates rejected

**25 October 2026 — bounded source screen, no approved sound mix.** The Fight Night edit should start with the audio recorded at the actual contact, not a library punch. Existing practice boxing clips had no audio streams. I checked public sources to see whether an audio-bearing boxing file would support a source-first test. None establishes usable original impact sound.

These files remain in ignored `media/fight-practice/`; generated contact images remain ignored. No practice-source original, derivative, or sound asset is added to Git. The Army file was downloaded only for this local source screen. Evworo's ShareAlike condition makes it especially unsuitable as a casually committed proof.

**Transfer rule for Staffy:** retain each camera take's audio with its exact video source and timecode. Before adding sound, verify visible contact and audition that timecode's original recording. A media container with an audio stream is not proof of ring ambience or impact; a waveform transient is not proof that a glove landed. If the Staffy sources contain an edited soundtrack, a muted camera track or only silent footage, record that explicitly and build removable, separately licensed effects only against verified action. Both local Gemma audio variants failed known controls in the [audio review study](FIGHT-LOCAL-AUDIO-REVIEW-STUDY.md), so they cannot certify a source or mix. Objective checks can flag silence/clipping/sync; independent editing-staff acceptance is still required before a finished client soundtrack is called good. The owner is not the routine practice-review gate.
