## Actual source and safety decision

The first missing capability was a **seekable editable type layer over real moving human footage**, not another FFmpeg wrapper. HyperFrames supplied it with one pinned local install. Herk provided an observed craft example and its open code/licence/installer were inspected; its complete kit was not installed. The source performer, song and whoosh in this experiment are each individually documented in `project.json` under [Mixkit's video](https://mixkit.co/license/modal/videoFree/) and [music](https://mixkit.co/license/modal/musicFree/) free licences. Their full files remain ignored in `media/`; public repo receives only transformed proof frames and source code. [Space Grotesk](https://github.com/google/fonts/tree/main/ofl/spacegrotesk) is distributed with its SIL OFL licence.

This matrix is not a claim that all candidates passed Windows runtime tests. It prevents unreviewed installers and makes the one real local test easy to repeat. A downloaded skill file by itself has no quality status.
